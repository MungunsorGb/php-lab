# PHP Step-by-Step Lab

## Төслийн танилцуулга

Энэхүү төсөл нь Интернэт орчны программчлал хичээлийн PHP Step-by-Step лабораторийн ажил юм. PHP хэлний үндсэн ойлголтоос эхлэн HTML форм боловсруулах, MySQL өгөгдлийн сантай холбогдох, CRUD үйлдэл хийх, session болон хэрэглэгчийн нэвтрэх системийг хэрэгжүүлсэн.

## Ашигласан технологи

- PHP 8
- HTML
- MySQL / MariaDB
- XAMPP (Apache, MySQL)
- phpMyAdmin
- PDO
- Git, GitHub

## Хэрэгжүүлсэн функцүүд

- PHP хувьсагч, массив, функц, нөхцөл, давталт
- HTML формоос GET болон POST хүсэлт боловсруулах
- Тооны машин болон үнэлгээ тооцоолох
- PDO ашиглан MySQL өгөгдлийн сантай холбогдох
- Хэрэглэгчийн мэдээлэл нэмэх, харах, засах, устгах (CRUD)
- Мэдээлэл хайх
- Session ашиглан хэрэглэгчийн төлөв хадгалах
- password_hash() болон password_verify() ашиглах
- Хэрэглэгч бүртгүүлэх, нэвтрэх, гарах

## XAMPP ашиглан ажиллуулах заавар

1. XAMPP суулгана.
2. Apache болон MySQL үйлчилгээг ажиллуулна.
3. Төслийн `php-lab` хавтсыг XAMPP-ийн `htdocs` хавтсанд байрлуулна.
4. Browser дээр `http://localhost/phpmyadmin` хаягийг нээнэ.
5. `database/phplab.sql` файлыг phpMyAdmin-ийн Import хэсгээр импортолно.
6. `includes/dbh.inc.php` файлын database холболтын тохиргоог өөрийн орчинд тааруулна.
7. Browser дээр `http://localhost/php-lab/` хаягийг нээж ажиллуулна.

## Өгөгдлийн сан

`database/phplab.sql` файл нь лабораторийн өгөгдлийн сангийн SQL бүтэц болон шаардлагатай өгөгдлийг агуулна.

Өгөгдлийн сантай PDO болон prepared statement ашиглан ажилласан.

## Аюулгүй байдал

- SQL injection-ээс хамгаалахад prepared statement ашигласан.
- HTML гаралтыг htmlspecialchars() ашиглан боловсруулсан.
- Нууц үгийг plaintext хэлбэрээр хадгалахгүй, hash болгосон.
- Session ашиглан хэрэглэгчийн нэвтрэх төлөвийг удирдсан.

## Дүгнэлт

Энэхүү лабораторийн ажлаар PHP-ийн үндсэн синтакс, форм боловсруулах, MySQL өгөгдлийн сантай холбогдох, CRUD үйлдэл хийх болон хэрэглэгчийн бүртгэл, нэвтрэх систем боловсруулах дадлага хийсэн. Мөн Git, GitHub ашиглан төслийн хувилбаруудыг удирдах мэдлэгээ бататгасан.
